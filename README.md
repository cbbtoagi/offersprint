# 冲刺Offer · 算法冲刺 × 大模型八股 三合一离线 App

面向秋招/实习**算法岗**的全流程面试准备应用：**LeetCode 热题算法冲刺 + 大模型八股速刷 + 模拟面试**，一套代码覆盖 **macOS / iPhone / Android** 三端，完全离线。

> 下载安装包请前往 [Releases](../../releases)。

## 功能总览

### ⌨️ 算法冲刺（LeetCode 热门 162 题 / 25 专题）
- **卡片学习流**：读题（含样例与审题诀窍）→ 思路逐层揭示（暴力→优化，含步骤拆解/示例走查/易错点）→ 带注释 Python 最优解 → 评测
- **默写评测**：看题默写代码，LCS 相似度打分 + 22 类结构命中检测 + 逐行 diff 高亮
- **思路自述**：模拟面试口述，语音输入（系统识别，可离线）+ 关键点自评
- **ACM 机考模式**：12 道手写经典专题 + 全题库 ACM 版代码
- **大厂高频**：字节/腾讯/美团/华为/阿里 等 12 家高频标签直达

### 📚 大模型八股（401 题 / 10 大领域）
- 领域：深度学习基础 · Transformer · 预训练 · 后训练与对齐 · 强化学习与推理模型 · Agent 与 Harness · 具身智能与 VLA · 自动驾驶与世界模型 · 手撕代码 · 场景设计
- 每题：一句话核心 + 分层详解 + 背诵要点 + 高频追问链 + 参考实现；**LaTeX 公式完整渲染**
- **项目实战**：10 个深度拆解项目（MiniGPT / FlashAttention / LoRA / GRPO / 推理引擎 / Agent Harness / VLA / BEV / 世界模型）
- **面经库**：31 家公司轮次结构、考察重点、高频真题

### 🎙 模拟面试
限时作答 + 自动录音 + 语音转写 + 参考答案对照 + 自评战报；**面试官追问模式**（答完追加高频追问）、**按公司组卷**、TTS 朗读题目

### ✨ 通用
- **SM-2 间隔重复**：算法与八股双复习队列，首页今日任务统一汇总
- 错题本、随手记（文字+语音）、打卡热力图、领域掌握度
- 学习数据导出/导入（JSON 备份）
- **完全离线**：题库内置、数据存本地、录音不上传、零网络请求

## 三端安装

| 平台 | 文件 | 安装方式 |
|---|---|---|
| **macOS** | `offersprint-x.x.x-macos.dmg` | 打开拖入「应用程序」 |

## 数据与隐私

- 学习进度、评测记录、笔记、录音全部存本机（双 SQLite 库 + 应用沙盒）
- 算法与八股学习进度独立存储、互不影响
- 语音转写/朗读使用系统能力，开启端侧识别后可完全离线
