# 面试速刷 · 大模型算法面试离线 App

面向秋招/实习的**大模型算法岗**离线刷题与模拟面试应用，一套代码覆盖 **macOS / iPhone / Android** 三端，完全离线可用。

> 下载安装包请前往 [Releases](../../releases) 页面。

## 核心特性

- **完全离线**：题库内置，学习数据存本地 SQLite，录音仅保存在本机，无任何网络上传
- **SM-2 间隔重复**：记得 / 模糊 / 忘了三档自评，到期优先、按面试频率补新题，错题自动沉淀错题本
- **模拟面试**：限时作答 + 自动录音 + 语音转写 + 参考答案对照 + 自评战报，薄弱题自动进入复习队列
- **面试官追问模式**：每题答完自动追加该题高频追问（半场限时，可对照答案）
- **按公司组卷**：对接面经库选择目标公司，优先出该公司高频真题
- **TTS 朗读**：题目/追问一键朗读（系统离线语音），通勤速听
- **随手记**：文字 + 标签 + 语音速记，可关联题目；错题本、18 周打卡热力图、领域掌握度、学习数据导出/导入

## 三端安装

| 平台 | 安装包 | 说明 |
|---|---|---|
| macOS | `面试速刷-x.x.x-macos.dmg` | 打开 DMG 拖入「应用程序」 |
| Android | `面试速刷-x.x.x-android.apk` | 直接安装（需允许未知来源） |
| iPhone | `interview-flash-x.x.x-ios.ipa` | 未签名 IPA，用爱思助手/Sideloadly 输入 Apple ID 签名安装（免费 7 天），详见下文 |

### iPhone 安装（IPA 手动签名，无需命令行）

1. 下载 Release 里的 `interview-flash-x.x.x-ios.ipa`（未签名包）
2. 电脑安装 [爱思助手](https://www.i4.cn/)（或 Sideloadly / AltStore），数据线连接 iPhone
3. 爱思助手 → 应用游戏 → 安装本地应用 → 选择该 IPA → 登录你的 Apple ID 签名安装
4. 手机上：设置 → 通用 → VPN与设备管理 → 信任该开发者证书

> 免费 Apple ID 签名 7 天有效，到期重复安装即可；也可用 Xcode 侧载（`bash scripts/ios_install.sh`）。

## 数据与隐私

- 学习进度、笔记、录音全部保存在本机应用沙盒内
- 「导出学习数据」生成 JSON 备份走系统分享；换机用「导入」粘贴恢复
- 语音转写使用系统能力：iOS/Android 开启端侧听写后可完全离线
